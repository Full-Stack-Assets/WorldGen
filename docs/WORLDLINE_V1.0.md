# Worldline 1.0 — Worldline One

Worldline 1.0 is the first production release that presents the Earth, time, branching, evidence, recursive-research, Cosmos, and Chronos systems as one coherent application.

## Product identity

**Version:** `1.0.0`  
**Codename:** `Worldline One`

The human-facing grammar is deliberately simple: **3D space + navigable time**. Possibility, uncertainty, memory, evidence, model disagreement, branch ancestry, and research history appear as contextual lenses rather than additional geometric axes.

## First Contact

The first fresh normal-motion visit now opens with a 1.4-second, immediately skippable visual sequence: a luminous point becomes a worldline, faint alternative trajectories appear, and the interface resolves into **WORLDLINE / WORLDLINE ONE**.

The application itself initializes underneath the overlay, so First Contact is presentation rather than a loading gate. A stored seen flag prevents repeated automatic playback. A World control can replay the sequence. Users with `prefers-reduced-motion: reduce` bypass it.

## Future Landscape

Worldline 1.0 adds a deterministic Future Landscape for larger branch sets. Committed branch metric vectors are normalized into a stable SVG projection with exact ancestry lines and a normalized divergence value from the root worldline.

The projection contains no random numbers and is independent of input branch ordering. Selecting a landscape point selects the exact underlying branch.

The visualization is explicitly labeled:

> **Scenario geometry · not probability**

No landscape coordinate, family, or divergence value is presented as a calibrated future probability.

## Earth Native

The v0.3 Earth Native system remains the default real-Earth path:

- free Open Earth network view using pinned MapLibre and OpenFreeMap/OpenStreetMap-derived geography;
- globe projection when supported, Mercator fallback otherwise;
- `READY`, `DEGRADED`, `UNAVAILABLE`, and `FALLBACK` provider health;
- automatic procedural fallback without canonical-state mutation;
- versioned New Bedford source/provenance package;
- independent **SOURCE TIME** and **SIMULATION TIME**;
- Truth Lens and source inspection.

No paid geospatial credential is required for the mandatory release path.

## Discovery Engine

The v0.5 Discovery Engine persists bounded recursive research as a versioned local ledger. A source-conflict cycle can record observation, anomaly, competing hypotheses, frozen evaluation contract, independent verification, promotion decision, Reality Wake, and reopening receipts.

Generator and verifier identities remain distinct. Candidates cannot replace their deciding evaluator. Only reversible machine-verifiable low-risk rendering/data-normalization candidates are eligible for automatic promotion. Architecture, policy, model, benchmark, authority, and scientific-claim changes remain gated.

Model Worldline derives evidence/decision ancestry directly from those receipts.

## Chronos Paradigm

The v0.7 Chronos browser arena provides a small deterministic experiential layer:

- movement records exact samples;
- **Anchor** captures an exact sample boundary;
- **Echo** replays the exact post-anchor samples;
- **Convergence** uses a fixed geometric threshold;
- **Reset** restores the same initial state.

Chronos is explicitly a **fictional gameplay mechanic inspired by worldline/spacetime concepts**. Its state does not mutate canonical simulation branches and the gameplay abilities are not represented as experimentally verified physics.

## Cosmos

The catalog includes:

- WorldGen Prime;
- New Bedford / Earth;
- Moon;
- Mars;
- Venus;
- Europa;
- Titan;
- three Asterion speculative variants.

Observed Solar-System identity and rendered browser-surface state remain separate. Named Solar-System bodies can remain `OBSERVED` while their current local browser surfaces are `GENERATED`. Asterion remains entirely `SPECULATIVE`.

## Chronos interchange

The provider-independent export schema is `worldline-chronos-v0.7`. It includes world and surface epistemic classes, family/variant state, spatial/reference-frame metadata, terrain-source status, time, branch ancestry, events, snapshots, metrics, seeds, and replay commitment.

## Benchmark Lab

Worldline maintains compatibility/export contracts for 4DWorldBench-style temporal render bundles and Omni-WorldBench-style interaction traces. Adapter readiness is not benchmark success. An external score is not attached unless the external benchmark was actually executed to completion.

## Accessibility and resilience

1.0 adds visible keyboard focus styles, keyboard-selectable Future Landscape points, keyboard/button Chronos controls, accessible SVG labels, mobile layout improvements, and reduced-motion suppression for non-essential animation.

A zero-credential smoke contract verifies procedural boot, no-network Earth fallback, deterministic replay, local research initialization, and local Chronos initialization.

## Evidence boundary

Worldline 1.0 is **not a calibrated forecast or oracle**. It does not claim a fully validated municipal digital twin, realistic interacting human populations, formal manifold geometry, external benchmark success without executed receipts, observed exoplanet surfaces without evidence, physically real Chronos abilities, or unrestricted self-modification.

**Visual fidelity must not outrun epistemic fidelity.**

## Production gate

2. `main` type-check, full Vitest suite, and production build;
3. GitHub Pages build, artifact verification, and deployment;
4. `v1.0.0` release/tag creation against that same deployed commit.
